* Fonctionnalité version 1

- Fonctionnalité  1 :
Description :
Le joueur peut déplacer son personnage dans le labyrinthe afin de le changer de case
Ca permet au joueur d'avoir accès a toute le labyrinthe dans son entièreté
Le critère doit juste être fonctionnel et simple pour l'instant

- Critère de validation :
    - Critère 1 : Le joueur peut se déplacer dans les 4 directions (Haut, Bas, Gauche, Droite)
    - Critère 2 : La position du joueur elle est mise à jour après chaque déplacement
    - Critère 3 : Le joueur ne peut pas sortir des limites de la carte
    - Critère 4 : Déplacement visible et vérifiable dans le programme

- Fonctionnalité 2 :
Description :
Le joueur peut attaquer un ennemi quand il est à sa portée
Quand le joueur attaque, la vie de l'ennemi baisse
Pour l'instant on doit avoir une attaque simple qui marche et qui permet de verifier l'interaction entre ennemi et joueur

- critères de validation :
    - critère 1 : le joueur peut lancer une attaque.
    - critère 2 : l'attaque touche uniquement un ennemi valide, par exemple un ennemi proche ou à portée.
    - critère 3 : les points de vie de l'ennemi diminuent après une attaque réussie.
    - critère 4 : si les points de vie de l'ennemi atteignent 0, l'ennemi est considéré comme vaincu
