* Fonctionnalité version 1

- Fonctionnalité  1 :Déplacement
Description :
Le joueur peut déplacer son personnage dans le labyrinthe afin de le changer de case
Ca permet au joueur d'avoir accès a toute le labyrinthe dans son entièreté
Le critère doit juste être fonctionnel et simple pour l'instant

- Critère de validation :
    - Critère 1 : Le joueur peut se déplacer dans les 4 directions (Haut, Bas, Gauche, Droite)
    - Critère 2 : La position du joueur elle est mise à jour après chaque déplacement
    - Critère 3 : Le joueur ne peut pas sortir des limites de la carte
    - Critère 4 : Déplacement visible et vérifiable dans le programme

- Fonctionnalité 2 : Création de labyrinthe
Description :
Création d'un labyrnthe sour la forme de grille, chaque case de la grille peut soit être un mur
soit un chemin accessible
Le joueur doit apparaitre dans une case de départ, puis se déplacer unniquement sur les cases accessibles

- critères de validation :
    - critère 1 : Le labyrinthe est créer sous forme de grille avec des murs et des chemins
    - critère 2 : Le joueur est placé sur une case valide, donc sur un chemin accessible et pas dans un mur
    - critère 3 : Il existe au moins un chemin possible entre le départ et l'arrivé
    - critère 4 : Le joueur ne peut pas pas traverser les murs ni sortir des limites du labyrinthe

- Fonctionnalité 3 : Afficher avec un moteur :
Description :
Le moteur d’affichage permet de représenter visuellement les éléments du jeu
Il affiche le labyrinthe, le joueur, les murs, les chemins et éventuellement la sortie ou les objectifs
Il sert à séparer la logique du jeu de son affichage afin de rendre le projet concret et visuel

- critère de validation :
    - critère 1 : Le moteur affiche correctement le moteur à l'écran
    - critère 2 : Le joueur est visible et affiché au bon endroit dans
    - critère 3 : Les murs et les chemins sont différent visuellement
    - critère 4 : l'affichage se met à jour correctement l'orsque l'état du jeu change

- Fonctionnalité : mur :
Description :
Le moteur affiche un carré de couleur différente afin de représenter un mur,
le joueur ne pas marcher sur ce carré et ne peux pas le traverser (ça vaut aussi pour les attaques)

- critère de validation :
    - critère 1 : Ne doit pas être traversable
    - critère 2 : Le joueur ne doit pas pouvoir apparaître sur un mur
    - critère 3 : Le joueur ne doit pas pouvoir attaques au travers

- Fonctionnalité : piege :
Description :
Le moteur affiche une case qui se fond partiellement avec le fond de l'image
de façon à ce qu'il soit peu visible.
Le joueur, lorsqu'il marche dessus, subis des dégats et le piège se désactive

- critère de validation :
    - critère 1 : Le joueur doit pouvoir marcher dessus
    - critère 2 : Le piège doit pouvoir s'activer lorsque le joueur passe dessus
    - critère 3 : Le piège doit infliger des dégats et se désactiver lorsque le joueur marche dessus
